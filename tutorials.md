# Tutorials and Learning Resources

Authoritative documentation, official guides, and benchmark write-ups for going deeper on long-context LLMs and retrieval-augmented research synthesis.

---

- **[Prompt engineering for long context — Anthropic documentation](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/long-context-tips)**
  Official guidance on structuring prompts (document placement, quote extraction, query placement) to reduce "lost in the middle" style failures in practice.

- **[LangChain documentation — Retrieval](https://python.langchain.com/docs/concepts/retrieval/)**
  Official conceptual and how-to guide covering retrievers, chunking strategies, and RAG pipeline construction referenced in the mitigation-strategies section of the paper.

- **[Hugging Face — LLM Course, "Retrieval Augmented Generation"](https://huggingface.co/learn)**
  Free official Hugging Face course modules covering embeddings, vector search, and RAG pipeline construction.

- **[NVIDIA/RULER README and leaderboard](https://github.com/NVIDIA/RULER)**
  Step-by-step instructions for reproducing the RULER benchmark evaluation locally, useful for hands-on experimentation with context-length degradation.

- **[ACL Anthology — LongBench / LongBench v2 papers and appendices](https://aclanthology.org/2024.acl-long.172/)**
  Full methodology and task-construction appendices for LongBench, useful for understanding benchmark design trade-offs discussed in Section 5 ("Research Challenges and Limitations") of the paper.
